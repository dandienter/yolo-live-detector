# YOLO Live Detector

Real-time object detection in the browser using YOLOv8n + ONNX Runtime Web.

## Live Demo
https://43-128-108-162.sslip.io/yolo/

## Features
- Live camera object detection (phone/laptop)
- YOLOv8n running locally in browser via ONNX
- Bounding boxes + labels, FPS indicator
- Confidence threshold slider
- Front/back camera switch
- Save detection snapshot
- Mobile-friendly, lightweight neobrutalism UI

## Tech
- YOLOv8n (ONNX)
- ONNX Runtime Web
- Vanilla JS + getUserMedia

## Run locally
Just open `index.html` in a browser (HTTPS or localhost required for camera access).
